# 🤖 AI Chat Bot App

A modern AI Chat Bot built using MERN Stack + Gemini AI API.

---

##  Features

- ✨ Beautiful Modern UI
- 🤖 Gemini AI Integration
- 💬 Real-time AI Responses
- 🌙 Glassmorphism Design
- ⚡ Fast & Responsive
- 🔥 React + Vite Frontend
- 🧠 Express Backend

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Framer Motion
- Axios

### Backend
- Node.js
- Express.js
- Gemini AI API
- dotenv
- cors
